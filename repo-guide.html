Student guide

How to use the notes and sample-code repository

Use this page every time you practise. Read the matching handbook topic first, open the suggested repository folder, run one example, and then make one small change. You are not only reading C++; you are building a habit of compiling, observing, and explaining.

The learning loop: read the note → open the folder → compile → run → change one line → run again → explain the output.
01 · Setup once

Prepare VS Code and a compiler

VS Code is your editor. You still need a compiler such as GCC/G++, Clang, or MSVC. Open the repository folder in VS Code, then open Terminal → New Terminal.

cd path\to\Advanced-cpp-sample-codes
code .

Check that the compiler is available:

g++ --version

On Windows with MinGW, run the executable with .exe. On Linux/macOS, run it with ./.

02 · Follow the sequence

Open folders in course order

Start with the numbered folders. The number is the classroom order, while the original folder name remains visible after the prefix.

  • 01-Structs → basic data modelling
  • 02-FunctionsLearning → functions and reuse
  • 03-Datatype-modifiers → types and modifiers
  • 04-Conditional-Iterators → decisions and loops
  • 05-Array → arrays and collections
  • 06-Strings → text processing
  • 07-Pointers → addresses and ownership foundations
  • 08-ClassesandObjects → classes, inheritance examples, and Module 1/2 references
  • 09-Operators → operator examples for Module 3
  • 10-ExceptionHandling onward → robustness, STL, smart pointers, threading, networking, and linking

Do not jump to a later folder because the filename looks interesting. If a later example uses a name you do not know, return to the earlier folder and run the smaller example first.

03 · Run one example

Read, compile, run, change

For example, open 01-Structs, choose a .cpp file, and compile from that folder:

g++ -std=c++17 example.cpp -o example

Run it:

Windows: example.exe
Linux/macOS: ./example

Write down what you expected and what you observed. Then change one input, label, or calculation and compile again. If the output changes, explain why before moving on.

04 · Connect it to the handbook

Use the notes as your map

  • Module 0 explains the compiler, syntax, namespaces, terminal, and C versus C++.
  • Module 1 explains classes through the banking case study and points to 08-ClassesandObjects.
  • Module 2 explains inheritance and dynamic binding before you inspect the shape examples.
  • Module 3 explains overloading before you inspect 09-Operators.
